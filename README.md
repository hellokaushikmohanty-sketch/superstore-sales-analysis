# 📊 Superstore Sales Analysis using Python

An end-to-end Sales Analysis project built using **Python, Pandas, NumPy, and Matplotlib**. This project demonstrates the complete data analysis workflow, including data cleaning, exploratory data analysis (EDA), business insights, and data visualization using the Sample Superstore dataset.

---

## 📌 Project Overview

The objective of this project is to analyse retail sales data to discover meaningful business insights. The analysis covers sales performance, profitability, customer behaviour, regional trends, product performance, and discount analysis.

This project follows a structured data analyst workflow:

```
Load Data
    ↓
Inspect Dataset
    ↓
Data Cleaning
    ↓
Exploratory Data Analysis (EDA)
    ↓
Business Insights
    ↓
Data Visualization
    ↓
Executive Dashboard
```

---

## 🎯 Objectives

- Load and inspect the dataset
- Understand the structure of the data
- Check for missing values and duplicates
- Perform exploratory data analysis (EDA)
- Analyse sales and profit trends
- Identify top-performing customers and products
- Compare regional and category performance
- Visualise business insights using Matplotlib
- Build an executive summary dashboard



```bash

```


Run all cells.
